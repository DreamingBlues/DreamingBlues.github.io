Projects

AI Forecast Validation

Analyzed high-dimensional atmospheric data (1M+ observations per timestep) to validate performance and spectral fidelity of foundation weather models like ERA5. Designed Python ETL pipelines using xarray and h5netcdf into model-ready formats to support ML algorithms. Performed topography and synoptic weather station analysis to create insight-driven visualizations

Neural Network Image Classification

Developed an end-to-end machine learning pipeline for handwritten equation recognition using Handwritten Math Symbols dataset. Leveraged TensorFlow to train a CNN, achieving 99% test accuracy classification. Utilized OpenCV (CV2) for image preprocessing and segmentation to isolate handwritten input. Integrated Python-based automation with the Wolfram Alpha API to return computed solutions. Highlighting expertise in deep learning, computer vision, model optimization, and cloud-integrated API services.

Data-Driven Analysis of UFC Predictors

Analyzed a dataset, ~6,500 observations and ~100 predictors, identifying key factors influencing fight outcome. Applied dimensionality reduction. Implemented K-Means clustering for Fight Style interpretation. Applied Elo-Engine for unique fighter ranking Evaluated ML models: Random Forest, Support Vector Machine (SVM), and Extreme Gradient Boosting (XGBoost), achieving a peak accuracy of 62%. This Project was supervised by Prof. Katie Coburn.

Project DIANA

I contributed as a software developer for Project DIANA, where we built custom UAV software to detect and map gas concentrations in real time. Our mission was to protect endangered species and preserve biodiversity by reducing harmful emissions like nitrogen gas in vulnerable ecosystems. We secured a technology grant to acquire advanced drones equipped with Grove AQI sensors for air quality monitoring. I helped process atmospheric data using Arduino systems, enabling real-time interpretation across wide areas and generating actionable insights for environmental conservation.
